# 대형 결실 only/common 분할의 입력 민감성

작성일: 2026-09-22
대상: `post.cpp` 의 `cluster()` / `read_cluster()`
상태: **2026-10-23 수정 — 기본값을 `--common_mode local`(pair 단위 breakpoint 비교)로 교체. 아래 "고칠 수 있는 방향" 4번을 적용했습니다. 이전 방식은 `--common_mode kmeans`.**

---

## 요약

**결실 2 kb 이상에서 `_mut_only` / `_mut_common` 배정이 재현되지 않습니다.**
입력 read의 1%만 무작위로 덜어내도 only 비율이 최대 30 pp 움직입니다.

| HPRT1_large, 4–9 kb 결실 | only 비율 | 사용된 군집 수 |
|---|---|---|
| 전체 입력 | 15.3% | 27 |
| 99% 표본 A | **42.2%** | 30 |
| 99% 표본 B | **37.8%** | 27 |
| 99% 표본 C | **45.9%** | 30 |

세 표본은 **알고리즘이 완전히 동일**하고 입력만 1% 다릅니다.

중요한 단서: **탐지 자체는 안정적입니다.** 같은 다섯 실행에서 전체 호출
(only + common)은 53.0–54.0% 로 붙어 있습니다. 흔들리는 것은 "CRISPR 유래"와
"대조군에도 있는 artefact" 사이의 **분할**뿐입니다.

영향 범위:

- 결실 2 kb 미만 — **영향 없음** (0.2 pp 이내로 안정)
- 결실 2 kb 이상 — only 비율 재현 불가
- WT 위양성 (0.04–0.11%), 키메라 오보고 (16.7–19.8%) — 안정

## 원인

`post.cpp`:

```c
int cl_k=1,tt=1;
double min_error=..., min_k, reg=2000, error;
while(cl_k<500)
{
    ...
    error/=(double)point.size();   /* 평균 제곱 오차 */
    error = error+reg*cl_k;        /* 규제항은 절대값 */
    if(error<min_error){ min_error=error; min_k=cl_k; }
    cl_k=3*tt; tt++;               /* k 후보: 1,3,6,9,12,... */
}
auto cluster_data = dkm::kmeans_lloyd(point,min_k);
```

문제가 두 겹입니다.

**1. `min_k` 가 이산 선택입니다.** 오차는 점 개수로 나눈 **평균**인데 규제항
`reg*cl_k` 는 절대값입니다. 점이 몇 개만 늘거나 줄어도 평균 오차가 조금 변하고,
그 조금이 k를 한 칸(예: 24 → 27) 넘기면 **전체 분할이 다시 짜입니다.**
실측에서 같은 데이터의 99% 표본들이 k = 27, 30, 27 로 갈렸습니다.

**2. 같은 k에서도 초기 중심이 달라집니다.** `dkm` 의 k-means++ 초기화는 데이터
집합 전체에 의존합니다 (`random_plusplus`). 시드는 고정되어 있지만 점 집합이
바뀌면 뽑히는 초기 중심이 달라집니다. BCL11A 는 k 가 18 로 동일한데도 4–9 kb
구간이 42.2% → 40.1% 로 움직였습니다.

**왜 2 kb 이상에서만 문제가 되는가.** 군집 좌표는 `(ref_st, ref_ed)` 입니다.
작은 결실은 절단 부위 근처에 조밀하게 뭉쳐 군집이 뚜렷하지만, 큰 결실은 좌표가
넓게 흩어져 오차 지형의 골이 얕습니다. 그래서 `reg=2000` 고정 규제와 이산 k
격자가 큰 결실 쪽에서만 쉽게 뒤집힙니다.

## 실무상 의미

- **2 kb 미만 결실을 보고하는 분석은 영향 없습니다.** 논문의 주 대상 범위이고,
  이 구간은 모든 실행에서 0.2 pp 이내로 안정적입니다.
- **2 kb 이상 결실의 only/common 비율은 단일 실행 값으로 보고하면 안 됩니다.**
  같은 데이터에서 표본만 흔들어도 30 pp 이동이 나옵니다.
- 대형 결실의 **총 검출률**(only + common)은 안정적이므로, 이 구간에서는
  분할 이전의 총량을 보고하는 편이 재현 가능합니다.

## 고칠 수 있는 방향 (미적용)

1. **규제항을 점 개수에 비례시키기** — 평균 오차와 규제항의 단위를 맞추면
   입력 크기에 대한 의존이 사라집니다. 가장 작은 수정입니다.
2. **k 격자를 촘촘하게** — `1,3,6,9,...` 대신 연속 k 를 쓰면 한 칸 넘어갈 때의
   충격이 줄어듭니다. 계산량은 늘어납니다.
3. **k-means 를 여러 시드로 돌려 다수결** — 초기화 의존을 줄입니다.
4. **군집 대신 좌표 근접도로 직접 대조** — 대조군에 ±N bp 이내의 같은
   절단점이 있는지 보는 방식. 군집 단계를 아예 없앱니다.

어느 쪽이든 논문의 대형 결실 수치에 영향을 주므로, 적용 전에 원 데이터로
재현 확인이 필요합니다.
